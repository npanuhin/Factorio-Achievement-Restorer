Factorio Achievement Restorer

Re-enable Steam achievements in Factorio saves

Running the game with mods will still disable the achievements
Steam achievements remain enabled until another console command is executed or the map editor is opened. If gameplay mods are installed, Factorio disables Steam achievements at runtime directly in the game executable — this cannot be bypassed by modifying the save file and requires patching game binaries (outside the scope of this tool).
